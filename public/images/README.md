# Product Images Directory

This directory should contain synthetic, non-branded product images for the Ovux Biotech Solutions website.

## Required Images

Please add the following images to this directory:

1. **hero-lab-equipment.jpg** - Modern analytical laboratory scene (no people, no logos)
2. **hplc-column.jpg** - Generic stainless-steel HPLC column (no logos)
3. **gc-column.jpg** - Generic GC column
4. **lab-glassware.jpg** - Laboratory glassware (vials, caps, syringes)
5. **lab-equipment.jpg** - Laboratory equipment (pumps, detectors, balances)
6. **pharma-accessories.jpg** - Pharma production accessories (tubing, filtration units)

## Image Requirements

- **Format:** JPEG or PNG
- **Size:** Recommended 1200x800px or larger
- **Quality:** High resolution, suitable for web display
- **Content:** Synthetic, non-branded, copyright-safe images
- **No OEM Logos:** Must not contain Agilent, Waters, Thermo, Shimadzu, or any other OEM logos
- **No People:** Product images should not include people

## Image Sources

You can generate these images using:
- AI image generation tools (DALL-E, Midjourney, Stable Diffusion)
- Stock photo services (with appropriate licensing)
- Custom photography of generic equipment

## Usage

Images are referenced in the codebase using paths like `/images/hero-lab-equipment.jpg`.
