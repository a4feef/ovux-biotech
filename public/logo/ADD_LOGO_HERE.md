# Add Your Logo Here

## Quick Instructions

1. **Save your logo file(s) in this directory:**
   - Main logo: `ovux-logo.png` (or `.svg`)
   - Icon only: `ovux-icon.png` (or `.svg`)

2. **File formats:**
   - PNG with transparency (recommended)
   - SVG (best for scalability)

3. **Sizes:**
   - Main logo: 200-300px width
   - Icon: 64x64px or 128x128px

4. **The website will automatically:**
   - Use the logo in the navbar
   - Use the icon as favicon
   - Show text fallback if logo files don't exist

## Your Logo Description

Based on your logo design:
- Circular blue emblem with white X (4 quadrants)
- "OVUX" in bold dark text
- "biotech" in smaller italic text
- Clean, professional design

## After Adding Logo

1. Restart your dev server: `npm run dev`
2. Check the navbar - logo should appear
3. Check browser tab - icon should appear

The code is already set up to use your logo!
