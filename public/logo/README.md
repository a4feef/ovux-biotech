# Logo Files

Place your OVUX biotech logo files here.

## Required Files

1. **ovux-logo.png** or **ovux-logo.svg**
   - Main logo (full logo with text)
   - Recommended size: 200-300px width
   - Format: PNG (with transparency) or SVG

2. **ovux-icon.png** or **ovux-icon.svg** (optional)
   - Just the circular emblem/icon
   - Recommended size: 64x64px or 128x128px
   - Used for favicon and small displays

3. **ovux-favicon.ico** (optional)
   - Browser favicon
   - Size: 32x32px or 16x16px
   - Can be generated from the icon

## File Naming

The code expects:
- Main logo: `ovux-logo.png` or `ovux-logo.svg`
- Icon: `ovux-icon.png` or `ovux-icon.svg`
- Favicon: `favicon.ico` (in `/public/` root)

## Logo Description

Based on your logo:
- Circular blue emblem with white X pattern (4 quadrants)
- "OVUX" text in bold, dark gray/black with drop shadow
- "biotech" text in smaller italic font below
- Clean, modern, professional design

## Usage

The logo will be used in:
- Navbar (top of every page)
- Footer (optional)
- Browser tab (favicon)
- Admin dashboard header
- Email templates (if added later)

## Tips

- Use PNG with transparency for best results
- SVG is preferred for scalability
- Keep file sizes small for fast loading
- Test on both light and dark backgrounds
